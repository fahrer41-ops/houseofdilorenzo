Splitroom

Pull the dialogue out of a one-stem mix and get music & effects back as its own track. Nothing is uploaded — the audio never leaves this tab.

1 · Load the mix

Video or audio — mp4, mov, wav, mp3, m4a. Up to six minutes.
Pick Choose File to reach the Files app, or Photo Library for a video.

2 · Set the split

Character
Balanced — the right starting point. Try the others if a word gets swallowed, or if music is leaking into the dialogue.
Centre width 45
How far off-centre a sound can sit and still count as dialogue. Raise it if the voice sounds thin; lower it if the score bleeds through.
Voice focus 45
Weights the split toward speech frequencies. High values reject centred bass and cymbals but can dull consonants.

When this isn't enough

This works by finding what sits dead centre in the stereo image, which is where dialogue almost always lives. It is instant and private, but it is arithmetic, not a trained model — if your music is also centred, or the file is mono, it can only do so much.

For those, use the Colab notebook in this repo. It runs the real Demucs model on Google's GPUs and you drive it from Safari, same as this page.
